**OSPF (Open Shortest Path First)** — протокол динамической маршрутизации класса **link-state** (протокол состояния канала), относится к группе **IGP** (Interior Gateway Protocol) — то есть используется для маршрутизации *внутри* автономной системы (одной сети/одной компании), а не между разными операторами (для этого есть BGP).

**Основные принципы:**

1. **Обмен состоянием линков, а не маршрутами.** В отличие от дистанционно-векторных протоколов (RIP), где роутеры просто говорят соседям "я знаю путь туда-то с такой-то метрикой", в OSPF каждый маршрутизатор рассылает информацию о состоянии *своих* каналов связи (LSA — Link State Advertisement): какие у него интерфейсы, с кем он соседствует, какая пропускная способность и т.д.

2. **Топологическая база данных (LSDB — Link State Database).** Получая LSA от всех маршрутизаторов в зоне (area), каждый узел строит у себя полную карту топологии сети. В итоге все роутеры в одной area имеют идентичную LSDB.

3. **Алгоритм Дейкстры (SPF — Shortest Path First).** На основе построенной топологии каждый маршрутизатор самостоятельно вычисляет кратчайшие пути до всех остальных сетей — строится дерево кратчайших путей с самим собой в корне. Результат заносится в таблицу маршрутизации.

4. **Метрика — cost.** Рассчитывается исходя из пропускной способности интерфейса (по умолчанию: reference bandwidth / bandwidth интерфейса). Чем выше скорость канала, тем ниже cost, тем предпочтительнее путь.

5. **Иерархия зон (Areas).** Для масштабируемости сеть делится на области:
   - **Area 0 (backbone)** — обязательная магистральная зона, через которую должны проходить все остальные area.
   - **Non-backbone areas** — периферийные зоны, подключаются к backbone через **ABR** (Area Border Router).
   
   Это снижает размер LSDB и объём пересчётов SPF в каждой отдельной зоне.

6. **Установление соседства (adjacency).** Маршрутизаторы обнаруживают друг друга через Hello-пакеты (multicast 224.0.0.5), согласовывают параметры (таймеры, area ID, аутентификация, MTU) и переходят в состояние **Full** — полное соседство с синхронизированной LSDB.

7. **Быстрая сходимость.** При изменении топологии (обрыв линка, отказ узла) затронутые маршрутизаторы рассылают обновлённые LSA, и все узлы в area пересчитывают SPF заново — сходимость обычно быстрее, чем у дистанционно-векторных протоколов.

8. **Роли маршрутизаторов:**
   - **DR (Designated Router) / BDR (Backup DR)** — выбираются в multi-access сетях (Ethernet) для снижения числа adjacency (все общаются через DR, а не друг с другом напрямую).
   - **ABR** — соединяет несколько area.
   - **ASBR (Autonomous System Boundary Router)** — граница с другими протоколами маршрутизации (например, редистрибуция BGP-маршрутов в OSPF).

Использует IP протокол напрямую (protocol 89), без TCP/UDP.
